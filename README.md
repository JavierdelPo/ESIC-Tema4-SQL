# ESIC - Tema 4: SQL

Repositorio de las prácticas del Tema 4 de SQL y Bases de Datos del Título Superior en Data Science de ESIC University.

## Contenido del repositorio

- **practica_1.sql:** creación de una base de datos, creación de tablas e inserción de registros de animales en el zoológico ParaiZoo.
- **practica_2.sql:** diez consultas SQL sobre una base de datos de películas, utilizando filtros, operaciones numéricas, fechas y funciones de texto.
- **practica_3.sql:** pendiente de completar.

## Tecnologías utilizadas

- Visual Studio Code
- SQL
- MySQL 8.4
- SQLite
- SQLTools
- Git y GitHub

## Ejecución

La práctica 1 se ejecuta mediante MySQL y la práctica 2 mediante SQLite, utilizando la base de datos moviebig.db proporcionada para la asignatura.
