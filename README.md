# ESIC - Tema 4: SQL

Repositorio de las tres prácticas del Tema 4 de SQL y Bases de Datos del Título Superior en Data Science de ESIC University.

## Contenido del repositorio

- **practica_1.sql:** creación de una base de datos, creación de tablas e inserción de registros de animales en el zoológico ParaiZoo. 5 ejercicios.
- **practica_2.sql:** consultas SQL sobre una base de datos de películas mediante filtros, operaciones numéricas, fechas y funciones de texto. 10 ejercicios.
- **practica_3.sql:** consultas avanzadas sobre películas, ordenación de resultados, operadores lógicos y tratamiento de valores nulos. 6 ejercicios.

## Tecnologías utilizadas

- Visual Studio Code
- SQL
- MySQL 8.4
- SQLite
- SQLTools
- Git y GitHub

## Ejecución

La práctica 1 se ejecuta mediante MySQL. Las prácticas 2 y 3 se ejecutan mediante SQLite, utilizando la base de datos moviebig.db proporcionada para la asignatura.

## Observaciones

El ejercicio 3 de la práctica 3 devuelve cero registros debido a que la base de datos no contiene horas de estreno. La consulta está diseñada para excluir fechas sin información horaria.

En el ejercicio 6 de la práctica 3 se incluyen los términos España y Spain, dado que los países aparecen registrados en inglés.
